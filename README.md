# Japan Shopping Buddy（日淘搭子）

> 2026 华为开发者大赛 · 小红书 Skill 创新赛参赛作品。
> 用户丢来日本商品链接/截图，一句话完成：日语识别 → 跨平台比价 → 阶梯精算真实到手价 → 生成购买确认单与购买指引。
> **中立工具定位：不代收代付、不自动下单**，成交由用户自行到原平台 / 代拍商完成。

## 解决什么痛点

日淘链路断裂：看不懂日文商品页、各家平台价格不透明、转运/关税/汇率算不清、代购层层加价。
日淘搭子把「识别 → 比价 → 试算 → 确认」整条链路封装成一个 Skill，到手价精确到分项，杜绝"估个大概"。

## 设计亮点（吸收比价类 Skill 最佳实践 + 跨境升级）

> 对照 ClawHub 市售比价 Skill（同类最高仅 A/70 分）逐项升级，评委可复测验证：

1. **双模式诚实输出**：证据充足走 Mode 1 强结论；单一货源/无同款走 Mode 2——明说「为什么不下强结论、还有什么没验证」，绝不编价格凑数（实战：森贝儿 C-81 乐天零结果，如实降级而非硬凑近似款）
2. **同款匹配置信度（高/中/低）**：近似款 ≠ 同款，比价结论必带置信度
3. **Caveats 防坑清单**：成色待核实 / 二手券后价陷阱 / 汇率时效 / 转运称重浮动 / 渠道覆盖，固定区块逐单提醒
4. **收货地第一变量**：非日元显示先反推日元原价（Amazon 按收货地自动换算 HKD/SGD），比价前必问收货地——直邮 vs 转运税差实测可达 ¥400
5. **全链路估算纪律**：汇率带快照时间戳，到手价只给区间不给假精确，分项透明可复核
6. **Provenance 硬约束（防幻觉报价）**：所有金额只能来自脚本结构化输出，确认单由 `arrival_price.py --quote` 直接渲染成 `quote.md`，模型只转述不填数（参照 Anthropic 官方 commerce-agents 的 provenance 设计）
7. **状态三态，不把失败说成没货**：`current` / `empty` / `unavailable` 三态 + 错误码枚举（`AUTH_MISSING` / `NET_UNREACHABLE` / `HTTP_ERROR` / `BAD_JSON` / `API_ERROR`），网络降级只说"数据暂不可用"，绝不说"查无此商品"
8. **入口分流 + 进度可视化**：单品页 / 搜索页 / 榜单页三种入口解析路径不同；六步进度清单（⬜1识别→⬜6购买）让多步链路对评委可见
9. **负向边界清晰**：SKILL.md 明确写"用户已明确在国内平台买、只需国内比价时不触发"，不抢其他比价工具的活
10. **税负按品类分档 + 免征额**：行邮税按 `--tariff-category` 取 13%/20%/50%，应征税额 ≤50 元自动免征并标注依据（实战：¥980,000 相机按 20% 多算 ¥2,900，¥3,520 万年笔正确免征）
11. **计算依据可审计 + 收货地参数化**：确认单每行都带来源（汇率来源+快照 / 转运价目文件 / 海关税率表与公告号）；收货地按 `--destination` 取 `cn`（完整行邮税模型）/`hk`（自由港 0 税）/`other`（未建模），未建模情形明确声明不编税率

## 完整链路（Pipeline 模式）

1. **识别**：解析日本商品链接/截图，译出商品名/成色/价格（非日元显示自动反推原价，收货地必问）
2. **路由**：渠道路由决策树判断最优渠道（references/channel_routing.md）
3. **比价**：乐天 RWS 一手 API（scripts/rakuten_search.py）；Amazon 页面快照兜底（代理 + 浏览器 UA + `/-/en/` 路径突破反爬）；中古源（Mercari/雅虎拍卖/骏河屋）走代拍中转或预置参考价
4. **试算**：到手价 = 商品 + 日国内运费 + 转运 + 汇率折算 + 行邮税（scripts/arrival_price.py）
5. **确认单**：购买确认单（明细+总额+商品信息），Reviewer 卡点交用户确认
6. **购买指引**：原平台链接 / 代拍商步骤，用户自行完成购买，Skill 不代收代付

## 目录

- `SKILL.md` — Agent 指令（六步 SOP + 设计亮点 + 双模式输出纪律 + Gotchas + 禁止行为）
- `scripts/` — `rakuten_search.py`（乐天 RWS）、`exchange_rate.py`（汇率双源+缓存）、`arrival_price.py`（到手价试算）、`smoke_test.py`（冒烟回归，`python3 scripts/smoke_test.py` 可一键复测 35 项脚本契约）
- `references/` — 渠道路由 / 到手价公式 / 转运价目 / 离线兜底快照
- `assets/` — 购买确认单模板（Generator）+ 图标
